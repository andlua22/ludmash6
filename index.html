UC5 — Додати студента
Ім'яДодати студента
Контекст використанняАдміністратор додає нового студента до обраної навчальної групи
Зона діїВеб-додаток «База студентів»
Рівень точностіКористувацька мета
Основна дійова особаАдміністратор
ПередумоваУ системі створена хоча б одна група
Мінімальні гарантіїДані не змінено, якщо валідація не пройшла
Гарантії успіхуСтудент збережений у базі даних з expelled = false
ТригерАдміністратор натискає кнопку «Додати студента»
Основний сценарій 1. Адміністратор відкриває форму додавання
2. Система завантажує список груп
3. Адміністратор вводить ім'я, прізвище, email
4. Адміністратор обирає групу
5. Адміністратор натискає «Зберегти»
6. Система перевіряє дані
7. Система зберігає студента в БД
8. Система оновлює список студентів
Розширення6a. Дані не валідні → показати помилку, повернення до кроку 3
UC6 — Відрахувати студента
Ім'яВідрахувати студента
Контекст використанняАдміністратор відраховує студента зі списку активних
Зона діїВеб-додаток «База студентів»
Рівень точностіКористувацька мета
Основна дійова особаАдміністратор
ПередумоваСтудент існує і не відрахований
Мінімальні гарантіїПри скасуванні дані не змінюються
Гарантії успіхуСтудент позначений як expelled = true
ТригерАдміністратор натискає «Відрахувати» біля студента
Основний сценарій 1. Адміністратор обирає студента зі списку
2. Адміністратор натискає «Відрахувати»
3. Система запитує підтвердження
4. Адміністратор підтверджує
5. Система надсилає PATCH-запит
6. Система встановлює expelled = true
7. Система оновлює список студентів
Розширення 4a. Адміністратор скасовує → повернення до списку
5a. Студента не знайдено → помилка 404
